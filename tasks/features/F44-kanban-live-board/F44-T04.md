# Task F44-T04 — War Room View (Columns + Cards)

**Feature:** F44
**Wave:** 1
**Type:** frontend
**Depends on:** F44-T01, F44-T02
**Status:** planned

## Objective

Implement the War Room board view with 6 columns rendering cards from
the warroom API. Cards show full detail matching the React WarroomCard
component's UX patterns.

## Dev Notes

- Renders inside `#board-warroom` div
- Consumes data from `fetchWarroom()` (T02)
- Reference UX: `dashboard/src/components/warroom/WarroomCard.tsx`

### War Room Columns
| Column | Key | Color Accent |
|--------|-----|-------------|
| Incoming | incoming | neutral (gray border-top) |
| Triaging | triaging | amber/yellow border-top |
| Assessed | needs_input | blue border-top |
| Promoted | promoted | green border-top |
| Deferred | deferred | slate border-top |
| Archived | archived | dim gray border-top |

### Card Anatomy (Jira-style)
```
┌─────────────────────────────┐
│ WR-20261127-001   [operator]│  ← ID badge + source icon
│                             │
│ Black Hawk Charlie —        │  ← Title (bold, truncated 60ch)
│ Monitoring Agent            │
│                             │
│ Framework health monitoring │  ← Body preview (2 lines, dimmed)
│ for agent success rates...  │
│                             │
│ [high] [squad] [monitoring] │  ← Priority badge + tags
│                             │
│ ✓ Promote → F39             │  ← Assessment + promoted_to link
│                        3h ago│  ← Relative timestamp
│ ████████████████████ 100%   │  ← Progress bar (if promoted)
└─────────────────────────────┘
```

### Card rendering function
```js
function renderWarroomCard(card) {
  // Source icons: operator=👤, agent=🤖, external=🌐
  // Priority colors: low=gray, medium=blue, high=orange, max=red
  // Assessment icons: promote=✓, defer=⏳, archive=📦, needs_input=❓
  // Progress: if promoted_to exists and pipeline done → 100%
  //           if promoted_to exists and pipeline running → pipeline progress
  //           else → no progress bar
}
```
