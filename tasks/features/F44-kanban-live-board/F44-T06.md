# Task F44-T06 — Light/Dark Mode Polish & Accessibility

**Feature:** F44
**Wave:** 2
**Type:** frontend
**Depends on:** F44-T03
**Status:** planned

## Objective

Polish the light/dark mode implementation with smooth transitions,
proper contrast ratios, and accessibility considerations.

## Dev Notes

### Theme System
- CSS variables on `:root` (dark default) and `[data-theme="light"]`
- Toggle button in header: sun icon (light) / moon icon (dark)
- Transition: `* { transition: background-color 0.2s, color 0.2s, border-color 0.2s; }`
- Persist: `localStorage.setItem('didio-board-theme', theme)`
- Init: check localStorage on page load, apply before first paint (in `<head>`)

### Light Mode Specifics
- Background: pure white (#fff) for surface, #f6f8fa for column backgrounds
- Text: #1f2328 (high contrast, WCAG AAA on white)
- Borders: #d0d7de (visible but not harsh)
- Cards: white surface, subtle shadow on hover
- Progress bars: slightly darker fills for visibility
- Priority badges: solid background variants (not transparent)

### Accessibility
- All interactive elements: `tabindex="0"`, `role="button"` where appropriate
- Focus ring: `outline: 2px solid var(--accent); outline-offset: 2px`
- Color contrast: minimum 4.5:1 for normal text (WCAG AA)
- Screen reader: `aria-label` on icon-only buttons
- Reduced motion: `@media (prefers-reduced-motion: reduce)` → disable animations

### Auto-detect system preference
```js
// On first visit (no localStorage), use system preference
if (!localStorage.getItem('didio-board-theme')) {
  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  document.documentElement.dataset.theme = prefersDark ? '' : 'light';
}
```
