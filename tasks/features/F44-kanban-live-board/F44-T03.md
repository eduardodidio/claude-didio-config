# Task F44-T03 — Board Shell, Layout & Theme System

**Feature:** F44
**Wave:** 1
**Type:** frontend
**Depends on:** F44-T01, F44-T02
**Status:** planned

## Objective

Create the main board HTML structure: header with board tabs, theme toggle,
stats bar, responsive column layout, and CSS variable-based theme system.

## Dev Notes

- File: `bin/board.html` (single file SPA)
- All CSS inline in `<style>` block (no external deps)
- All JS inline in `<script>` block
- CSS custom properties for theming: `--bg`, `--surface`, `--border`, `--text`, etc.
- Theme toggle: adds/removes `data-theme="light"` on `<html>`
- Persist theme choice to `localStorage.getItem('didio-board-theme')`

### Layout Structure
```
<html>
<body>
  <header>                  ← fixed top bar
    <logo />
    <board-tabs />          ← War Room | Standard
    <stats-bar />           ← dynamic counts
    <theme-toggle />        ← sun/moon icon
  </header>
  <main>
    <div id="board-warroom">  ← horizontal flex, scrollable
      <column *6 />
    </div>
    <div id="board-standard"> ← horizontal flex, scrollable
      <column *6 />
    </div>
  </main>
  <aside id="detail-panel">  ← slide-in from right, 400px wide
    <card-detail />
  </aside>
</body>
```

### CSS Architecture
- Variables defined in `:root` (dark) and `[data-theme="light"]` (light)
- BEM-like class naming: `.board`, `.board__column`, `.board__card`
- Utility classes: `.flex`, `.gap-4`, `.text-sm` (minimal, inline)
- Transitions on theme change (0.2s ease)
- Mobile: `@media (max-width: 768px)` → columns stack vertically
