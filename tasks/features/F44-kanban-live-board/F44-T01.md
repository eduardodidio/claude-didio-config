# Task F44-T01 — Python HTTP Server

**Feature:** F44
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Status:** planned

## Objective

Create a lightweight Python HTTP server that serves the board HTML and
provides JSON API endpoints for reading project state.

## Dev Notes

- File: `bin/didio-board-server.py`
- Python 3 stdlib only (http.server, json, pathlib, os, glob)
- Default port: 8844
- CORS headers for local dev
- Graceful shutdown on SIGINT/SIGTERM

### Routes

| Route | Method | Response |
|-------|--------|----------|
| `/` | GET | Serve `bin/board.html` |
| `/api/warroom` | GET | JSON: all cards from `logs/warroom/cards/*.json` |
| `/api/pipelines` | GET | JSON: all pipeline states from `logs/agents/pipeline-*.state.json` |
| `/api/features` | GET | JSON: feature list from `tasks/features/*/` with README metadata |
| `/api/squad` | GET | JSON: latest squad/bravo/charlie/delta reports |
| `/api/config` | GET | JSON: relevant config from `didio.config.json` |

### API Response Shapes

```json
// GET /api/warroom
{
  "cards": [...],           // full card JSONs
  "counts": {               // pre-computed counts
    "incoming": 0, "triaging": 0, "promoted": 6,
    "deferred": 3, "archived": 0, "needs_input": 0
  },
  "total": 10
}

// GET /api/pipelines
{
  "pipelines": [...],       // full state JSONs
  "counts": {
    "planned": 0, "running": 0, "done": 2, "failed": 2, "paused": 0
  }
}

// GET /api/features
{
  "features": [
    { "id": "F42", "name": "Squad Dashboard", "dir": "F42-squad-dashboard",
      "status": "done", "commit": "931e426" }
  ]
}
```

## Implementation details

- Use `http.server.HTTPServer` with custom `BaseHTTPRequestHandler`
- Route dispatch via path matching in `do_GET`
- Read JSON files with error handling (skip malformed files, log warning)
- Use `DIDIO_PROJECT_ROOT` env var for project root (fallback to cwd)
- Serve static files from same directory as the script

## Acceptance criteria

- [ ] AC1: `python3 bin/didio-board-server.py` starts on port 8844
- [ ] AC2: `GET /` returns HTML content-type with board.html
- [ ] AC3: `GET /api/warroom` returns valid JSON with cards array and counts
- [ ] AC4: `GET /api/pipelines` returns valid JSON with pipeline states
- [ ] AC5: `GET /api/features` returns valid JSON with feature list
- [ ] AC6: Malformed JSON files are skipped (server doesn't crash)
- [ ] AC7: CORS headers present (`Access-Control-Allow-Origin: *`)
- [ ] AC8: Server gracefully shuts down on Ctrl+C

## Test scenarios

- **Happy path:** Start server, fetch all endpoints, verify JSON structure
- **Empty state:** No warroom cards, no pipelines → empty arrays
- **Malformed file:** Corrupted JSON in cards/ → skipped, rest returned
- **Port conflict:** Port 8844 in use → clear error message
