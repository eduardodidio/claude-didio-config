# F33-T14 — DOB Fixture Library (Additional Fixtures)

- **Wave**: 4
- **Type**: test / docs
- **Depends on**: F33-T03, F33-T12
- **Status**: planned

## User Story

As a benchmark user, I want multiple fixture profiles representing different
scenarios so that I can benchmark across varied conditions.

## Objective

Create additional DOB fixture files beyond the basic example, representing
common benchmark scenarios.

## Dev Notes

The example fixture (T12) is a synthetic smoke test. This task adds fixtures
that represent realistic benchmark profiles:

1. `baseline-v1.json` — a "good" baseline representing a well-optimized run
2. `degraded.json` — a fixture with intentionally poor scores for regression testing
3. `minimal.json` — minimal feature (1 wave, 2 tasks) benchmark profile

**Files to create:**
- `tests/dob-fixtures/baseline-v1.json`
- `tests/dob-fixtures/degraded.json`
- `tests/dob-fixtures/minimal.json`

## Implementation Details

Each fixture follows the same schema as `example.json` (created in T12).
The `values` array should have exactly K entries (3 for standard runs).

Scores should be realistic and internally consistent (e.g., high
`guardrail_compliance` with high `rework_rate` is contradictory).

## Acceptance Criteria

- [ ] 3 new fixture files created in `tests/dob-fixtures/`
- [ ] All valid JSON: `for f in tests/dob-fixtures/*.json; do python3 -m json.tool < "$f" > /dev/null; done`
- [ ] Each has 12 dimensions with 3 values each
- [ ] `baseline-v1.json` has overall score > 80/120
- [ ] `degraded.json` has overall score < 50/120
- [ ] `minimal.json` has mid-range scores (50-80/120)

## Testing

- JSON validation for each file
- Score range check via Python

## Test Scenarios

- Happy: all fixtures load and score correctly
- Edge: fixture with extreme values (0, 10)
