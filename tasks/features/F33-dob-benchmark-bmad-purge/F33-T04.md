- **Wave**: 1

- **Depends on**: F33-T01, F33-T02

## User Story

As a framework maintainer, I want a `didio dob-score` command that aggregates
K run results into a single scored report so that I can compare configurations.

## Objective

Create `bin/didio-dob-scorer.sh` — reads K metrics.json files, computes mean
and stddev per dimension, and writes a summary report.

## Dev Notes

The scorer reads `docs/dob-dimensions.json` for dimension weights and metadata.
It reads `run-*/metrics.json` from a results directory (produced by T03 runner).

Use Python for the aggregation logic (called from bash wrapper). The project
already uses `python3 -c` extensively; for more complex logic, write an inline
Python script or a small `.py` file.

**Files to create:**
- `bin/didio-dob-scorer.sh`

**Files to edit:**
- `bin/didio` — add `dob-score` subcommand case

## Implementation Details

**Input:** `<results-dir>` containing `run-*/metrics.json`

**Output:** `<results-dir>/summary.json`

```json
{
  "fixture": "example",
  "k": 3,
  "timestamp": "2026-11-26T12:00:00Z",
  "dimensions": {
    "task_decomposition": {
      "mean": 7.33,
      "stddev": 0.47,
      "min": 7,
      "max": 8,
      "weight": 1.0,
      "weighted_score": 7.33
    }
  },
  "overall_score": 72.5,
  "overall_max": 120.0
}
```

The `overall_score` = sum of `weighted_score` across all dimensions.
The `overall_max` = sum of (max * weight) across all dimensions = 120.0 for V0.

## Acceptance Criteria

- [ ] `bin/didio-dob-scorer.sh` exists and is executable
- [ ] `didio dob-score --help` prints usage

- [ ] Summary contains mean, stddev, min, max per dimension
- [ ] `overall_score` correctly sums weighted scores
- [ ] Exit 0 on success, exit 1 on no metrics found
