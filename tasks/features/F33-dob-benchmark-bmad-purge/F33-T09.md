methodology so that results are reproducible and the scoring is transparent.

methodology, covering dimensions, scoring, running, and interpreting results.

## Implementation Details

Document structure:
1. **Purpose** — why DOB exists, what it measures
2. **Dimensions** — table of 12 dimensions with brief descriptions
3. **Scoring** — 0-10 scale, weights, rubric guidelines
4. **Running a Benchmark** — `didio dob-run` usage, fixture format
5. **Scoring Results** — `didio dob-score` usage, summary.json format
6. **Regression Gate** — `didio dob-regression` usage, CI integration
7. **Fixture Format** — JSON schema for fixture files
8. **Interpreting Results** — what good/bad scores look like
9. **K Value Rationale** — why K=3 (statistical confidence vs cost)
