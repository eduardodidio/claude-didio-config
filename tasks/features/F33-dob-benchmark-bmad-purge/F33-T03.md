# F33-T03 — DOB Runner Script

- **Wave**: 1
- **Type**: backend
- **Depends on**: F33-T01, F33-T02
- **Status**: planned

## User Story

As a framework maintainer, I want a `didio dob-run` command that executes K
benchmark runs against a fixture and collects raw results so that I can
objectively measure framework performance.

## Objective

Create `bin/didio-dob-runner.sh` — the benchmark orchestrator that runs a
fixture K times and collects per-run metric JSONs.

## Dev Notes

Follow the pattern of `bin/didio-run-pipeline.sh` for argument parsing and
config reading. The runner does NOT score — it only collects raw metrics.
Scoring is done by T04's scorer script.

The runner reads `dob.k`, `dob.fixtures_dir`, and `dob.results_dir` from
`didio.config.json` via `python3 -c` (same pattern as other scripts).

Each run should:
1. Create a results directory: `<results_dir>/<fixture-name>/<timestamp>/run-<N>/`
2. Capture timing, token counts, agent logs, test results
3. Write a `run-<N>/metrics.json` with raw measurements per dimension

For V0, the runner operates in **offline/synthetic mode**: it reads a fixture
file that provides pre-computed metric values (simulating what a real pipeline
run would produce). Real pipeline integration is future work.

## Implementation Details

```bash
#!/usr/bin/env bash
# didio-dob-runner.sh — Run DOB benchmark K times against a fixture
set -euo pipefail

# Read config
K=$(python3 -c "import json; c=json.load(open('didio.config.json')); print(c.get('dob',{}).get('k',3))")
FIXTURES_DIR=$(python3 -c "import json; c=json.load(open('didio.config.json')); print(c.get('dob',{}).get('fixtures_dir','tests/dob-fixtures'))")
RESULTS_DIR=$(python3 -c "import json; c=json.load(open('didio.config.json')); print(c.get('dob',{}).get('results_dir','logs/dob-results'))")

# Parse args: --fixture <name> [--k <N>]
# ...
```

**Output structure:**
```
logs/dob-results/<fixture>/<timestamp>/
  run-1/metrics.json
  run-2/metrics.json
  run-3/metrics.json
  summary.json  (written by scorer, not runner)
```

## Acceptance Criteria

- [ ] `bin/didio-dob-runner.sh` exists and is executable
- [ ] `bin/didio dob-run --help` prints usage
- [ ] `didio dob-run --fixture example --k 1` creates results dir with `run-1/metrics.json`
- [ ] `didio dob-run --fixture example --k 3` creates 3 run dirs
- [ ] Each `metrics.json` has 12 dimension entries matching the schema IDs
- [ ] `--k` flag overrides config value
- [ ] Exit 0 on success, exit 1 on missing fixture
