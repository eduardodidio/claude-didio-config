## User Story

As a CI pipeline, I want a smoke test that validates the DOB benchmark pipeline
end-to-end so that regressions in the benchmark tooling are caught automatically.

## Objective

Create `tests/F33-dob-smoke.sh` — an end-to-end test that exercises runner,
scorer, and regression gate with a synthetic fixture.

## Dev Notes

The smoke test should:
1. Create a temporary synthetic fixture
2. Run `didio dob-run --fixture <temp> --k 2` (K=2 for speed)
3. Run `didio dob-score <results-dir>`
4. Verify summary.json has correct structure
5. Create a fake baseline, run `didio dob-regression`
6. Verify PASS/FAIL logic

Use `DIDIO_HOME=$(pwd)` since we're in the framework repo.

**Files to create:**
- `tests/F33-dob-smoke.sh`
- `tests/dob-fixtures/example.json` (the example/synthetic fixture)
