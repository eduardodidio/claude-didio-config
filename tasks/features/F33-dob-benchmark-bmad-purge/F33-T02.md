- **Wave**: 0

- **Depends on**: (none)

## User Story

As a benchmark consumer, I want a machine-readable schema defining all 12 DOB
dimensions with scoring rubrics so that scores are consistent and reproducible.

## Objective

Create `docs/dob-dimensions.json` — the canonical definition of all 12 benchmark
dimensions with names, descriptions, scoring ranges, and rubric guidelines.

## Dev Notes

This is a new file. Use JSON (not YAML) to match the project convention.
Each dimension needs: `id`, `name`, `description`, `weight` (default 1.0),
`range` (min/max), and `rubric` (mapping from score to description).

Reference: the 12 dimensions are listed in `tasks/features/F33-_tmp-brief.md`.

Scoring is 0-10 integer scale per dimension. Weights allow future tuning
(all 1.0 for V0). The scorer (T04) will read this file at runtime.

## Implementation Details

**Files to create:**
- `docs/dob-dimensions.json`

**Schema structure:**

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "version": "1.0.0",
  "dimensions": [
    {
      "id": "task_decomposition",
      "name": "Task Decomposition Quality",
      "description": "Granularity, independence, and completeness of task breakdown",
      "weight": 1.0,
      "range": { "min": 0, "max": 10 },
      "rubric": {
        "0-2": "Tasks are monolithic, tightly coupled, or missing key work",
        "3-5": "Reasonable decomposition with some coupling or gaps",
        "6-8": "Clean, independent tasks with minor optimization opportunities",
        "9-10": "Optimal decomposition — minimal, independent, complete"
      }
    }
  ]
}
```

**All 12 dimensions:**
1. `task_decomposition` — Task Decomposition Quality
2. `parallel_efficiency` — Parallel Execution Efficiency
3. `context_isolation` — Context Isolation
4. `token_efficiency` — Token Efficiency
5. `test_coverage_delta` — Test Coverage Delta
6. `diagram_accuracy` — Diagram Accuracy
7. `guardrail_compliance` — Guardrail Compliance
8. `recovery_resilience` — Recovery Resilience
9. `learning_retention` — Learning Retention
10. `pipeline_autonomy` — Pipeline Autonomy
11. `time_to_feature` — Time to Feature
12. `rework_rate` — Rework Rate
