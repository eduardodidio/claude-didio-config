# F33-T05 — DOB Regression Gate

- **Wave**: 1
- **Type**: backend
- **Depends on**: F33-T01, F33-T02
- **Status**: planned

## User Story

As a CI pipeline, I want a `didio dob-regression` command that compares a
baseline score against a current score and blocks MRs that degrade beyond
a threshold so that framework quality never silently degrades.

## Objective

Create `bin/didio-dob-regression.sh` — reads two summary.json files (baseline
and current), compares each dimension, and exits non-zero if any dimension
degrades beyond the configured threshold.

## Dev Notes

Reads `dob.regression.threshold_pct` from `didio.config.json` (default 10%).
A dimension "degrades" if `(baseline_mean - current_mean) / baseline_mean * 100
> threshold_pct`.

The script should be CI-friendly: machine-readable output on stdout, human-
readable report on stderr.

**Files to create:**
- `bin/didio-dob-regression.sh`

**Files to edit:**
- `bin/didio` — add `dob-regression` subcommand case

## Implementation Details

**Usage:** `didio dob-regression <baseline-summary.json> <current-summary.json>`

**Exit codes:**
- 0: no regression beyond threshold
- 1: at least one dimension regressed beyond threshold
- 2: invalid input (missing files, bad JSON)

**Output (stdout):**

```json
{
  "verdict": "PASS",
  "threshold_pct": 10,
  "regressions": [],
  "improvements": [
    { "dimension": "token_efficiency", "baseline": 6.5, "current": 7.2, "delta_pct": 10.8 }
  ]
}
```

When verdict is "FAIL":

```json
{
  "verdict": "FAIL",
  "threshold_pct": 10,
  "regressions": [
    { "dimension": "test_coverage_delta", "baseline": 8.0, "current": 6.5, "delta_pct": -18.75 }
  ]
}
```

## Acceptance Criteria

- [ ] `bin/didio-dob-regression.sh` exists and is executable
- [ ] `didio dob-regression --help` prints usage
- [ ] Exit 0 when no dimension degrades beyond threshold
- [ ] Exit 1 when any dimension degrades beyond threshold
- [ ] Exit 2 on missing/invalid input files
- [ ] JSON output on stdout with verdict, regressions, improvements
- [ ] Threshold configurable via config and `--threshold` flag override

## Testing

- `bash -n bin/didio-dob-regression.sh` — syntax check
- Smoke test with crafted baseline/current (T12)

## Test Scenarios

- Happy: current better than baseline on all dims -> PASS
- Happy: current slightly worse but within threshold -> PASS
- Fail: current worse beyond threshold on 1 dim -> FAIL
- Edge: baseline dim is 0 (avoid division by zero)
- Error: missing baseline file -> exit 2
