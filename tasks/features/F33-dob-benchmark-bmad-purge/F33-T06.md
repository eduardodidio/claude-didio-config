# F33-T06 — CLI Wiring for DOB Subcommands

- **Wave**: 1
- **Type**: infra
- **Depends on**: F33-T01
- **Status**: planned

## User Story

As a framework user, I want `didio dob-run`, `didio dob-score`, and
`didio dob-regression` to work from the CLI so that I access DOB via the
standard `didio` entry point.

## Objective

Wire the 3 DOB subcommands into `bin/didio` dispatcher.

## Dev Notes

Edit `bin/didio` to add 3 new case entries in the main case/esac block.
Follow the existing pattern (e.g., `run-pipeline`, `token-monitor`).

Note: T03, T04, T05 create the actual scripts. This task only wires them
into the dispatcher. These 4 tasks (T03-T06) are all in Wave 1 and touch
different files, so they can run in parallel. The wiring references scripts
that may not exist yet — that's fine, `exec` will fail gracefully if the
script isn't there.

**Files to edit:**
- `bin/didio` — add `dob-run`, `dob-score`, `dob-regression` cases

## Implementation Details

Add after the `machine-scan` case:

```bash
dob-run)        exec "$DIDIO_HOME/bin/didio-dob-runner.sh" "$@" ;;
dob-score)      exec "$DIDIO_HOME/bin/didio-dob-scorer.sh" "$@" ;;
dob-regression) exec "$DIDIO_HOME/bin/didio-dob-regression.sh" "$@" ;;
```

## Acceptance Criteria

- [ ] `bin/didio dob-run --help` dispatches to runner
- [ ] `bin/didio dob-score --help` dispatches to scorer
- [ ] `bin/didio dob-regression --help` dispatches to regression gate
- [ ] No existing subcommands broken (`bash -n bin/didio`)

## Testing

- `bash -n bin/didio` — syntax check
- `grep 'dob-run' bin/didio` — wiring present

## Test Scenarios

- Happy: each subcommand dispatches correctly
- Error: unknown subcommand still shows help
