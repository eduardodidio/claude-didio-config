## Objective

from trigger to completion. Each journey tests a full user story with
real scripts (using DRY_RUN where live API would be needed).

### DRY_RUN Strategy
- All agent spawns use `DIDIO_DRY_RUN=1` to skip live API calls
- Pipeline state transitions are testable without API
- Signal files (pause/resume/cancel) are testable without API
- War Room card CRUD is testable without API
- Squad scanners read local files, testable without API
