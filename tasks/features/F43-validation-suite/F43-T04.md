## Test scenarios

### War Room Edge Cases
- **Empty title**: `didio warroom add ""` → expected: error
- **Missing fields**: Card JSON without `source` → triage behavior
- **Invalid status**: Card with `status: "bogus"` → list/triage skip behavior
- **Duplicate add**: Two `add` in rapid succession → distinct IDs

### Promote Edge Cases
- **Re-promote**: Promote same card twice → idempotent or error
- **Invalid recommendation**: Card with `recommendation: "bogus"` → error
- **No assessment**: Card without overlord_assessment → error
- **Feature dir exists**: Manual dir at next F-number → auto-increment

### Pipeline Edge Cases
- **Resume nonexistent**: `pipeline-resume F99` → clean error
- **Corrupted state**: Truncated JSON in state file → warning + skip
- **Stale state**: State file >24h old → detection

### Squad Edge Cases
- **Empty scan**: No pipelines, no cards, no security findings → clean report
- **Scanner failure**: One of Bravo/Charlie/Delta errors → others continue
- **Report collision**: Two squad scans in same second → distinct reports

### Mesh Edge Cases
- **Empty registry**: `~/.didio/mesh-registry.json` empty → clean init
- **Missing registry**: File doesn't exist → create + warn
