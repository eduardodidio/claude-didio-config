## Acceptance criteria

- [ ] AC1: K variation tests pass (K=1, K=2, K=5, K=10)
- [ ] AC2: Edge value tests pass (score=0 all dims, score=10 all dims, mixed extremes)
- [ ] AC3: Regression threshold boundary tests pass (exactly -10%, -10.01%, -9.99%)
- [ ] AC4: Zero baseline regression handled correctly
- [ ] AC5: Consistency test: same fixture 3x produces identical results
- [ ] AC6: Performance: K=10 fixture completes scoring in <5s
- [ ] AC7: Partial fixture (missing dimensions) behavior documented and tested
- [ ] AC8: Out-of-range values (11, -5, 999) behavior documented and tested
- [ ] AC9: Malformed JSON fixture produces clean error (exit 2)
- [ ] AC10: Empty values array handled gracefully
- [ ] AC11: Degraded vs baseline regression gate catches all regressed dimensions
- [ ] AC12: TAP output format: "ok N description" / "not ok N description"

## Test scenarios

- **K=1**: Single run, stddev must be 0, mean equals single value
- **K=5**: 5 runs, verify all 5 metrics.json created
- **Score boundaries**: [0,0,0] → mean=0, [10,10,10] → mean=10
- **Mixed extremes**: [0,10,5] → mean=5, stddev≈4.08
- **Regression boundary**: baseline=8, current=7.2 → delta=-10% → PASS at threshold=10
- **Regression boundary**: baseline=8, current=7.19 → delta=-10.125% → FAIL at threshold=10
- **Zero baseline**: baseline=0, current=5 → delta=+100% → no regression
- **Zero both**: baseline=0, current=0 → delta=0% → no regression
- **Malformed JSON**: truncated fixture → exit 2
- **Missing dimension**: fixture with 11/12 dims → behavior check
- **Concurrent**: 2 runners on same fixture simultaneously → no corruption
